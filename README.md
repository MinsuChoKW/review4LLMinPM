# LLMs in process mining: coding sheet

Supplementary data for *Large language models in process mining: Task coverage, analytical dimensions, and the verification gap*.

## File

`coding_sheet_81_studies.csv`: one row per included study (81) with bibliographic data, DOI, task group(s), line(s) of approach, regime, and the ten coded aspects A–J.

| Column | Content |
|---|---|
| ID, Bib key, Year, Authors, Title, Venue, DOI / URL | Bibliographic data |
| Task group(s) | Membership in the ten task groups|
| Line(s) of approach | Line within each group|
| Regime | Boundary transformation / Task substitution / Outside both regimes |
| A–E | Process mining dimensions: perspective, question, tool, evaluation source, domain |
| F–J | LLM dimensions: model, adaptation, functional role, external knowledge, runtime interaction |
| Discovery algorithms invoked, Geographic origin | Additional coded fields |

Multi-label cells are comma-separated; `None` = not reported. All counts in the article can be recomputed from this file.
